# 登录接续与验证体验修订（2026-11-15）

## 已落实

- 登录检测兼容 Discourse 的旧 `data-preloaded` 属性和新 `application/json` 脚本节点；优先读取页面内的真实用户，避免额外请求。
- 页面进入 interactive 阶段即可识别已有登录结果；普通页面内的隐式 Turnstile 不再被误认为整页挑战。
- 登录用途按入口的 HTTPS 域名和路径识别，重定向后仍保留用途。Connect 的 `/login` 不会被当成 Lindo 登录而自动关闭。
- 成功接收用户会话后关闭内嵌网页并切换首页；系统浏览器 OTP 接续仍保留独立流程。
- WebView 外层工具栏显示简短用途或当前域名，保留关闭、刷新及系统返回，不再重复 Connect 等网页标题。
- 点击验证直接启动平台验证流程，删除第二次确认弹窗。输入框内显示轻量验证状态；取消保留草稿，验证成功后恢复。
- Android 验证请求错误及超时进入可重试状态；关闭验证页不再冒充验证成功并解除冷却。
- 关于页去掉重复说明；清缓存使用单一确认，并等待磁盘清理完成后显示成功。诊断日志仍在诊断页面管理，清缓存不清除限流/验证冷却。
- 回复目标使用头像、姓名、楼层及单行摘要；展开回复保持同一视觉语言。保留跳转、高亮和返回。
- 账号移除确认使用现有统一对话框。
