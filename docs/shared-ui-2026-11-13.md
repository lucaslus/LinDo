# 统一界面与自适应布局（build 35）

原先新增的 `MacDesktopExperience.enabled` 把视觉与交互改进错误地限定在 macOS；该开关及文件已移除。公共页面不再根据操作系统选择字号、字重、图片预览、主题设置、登录入口或验证设计。宽窄布局继续由 `shouldUseWideSplitLayout` 根据窗口约束决定。

- 共用标题 16sp / SemiBold，正文 16sp / 25sp 行高，以及辅助文字层级。
- 小、标准、大字号统一为 0.95 / 1.0 / 1.12。旧三档偏好按档位迁移，新偏好使用 `ui_font_scale_v3`，防止标准字号每次启动再次放大。
- `AppAppearance` 负责全端外观及图标底色选择：跟随系统、浅色/白底、深色/黑底；平台只负责保存偏好和更新系统图标。
- 共用图标选择页与矢量素材。Android 使用 launcher alias 和 `values-night` 资源实现系统底色，桌面使用相同矢量素材渲染 Dock 图标；托盘仍是原生单色模板图标。
- 图片预览共用最大 560×360dp、保持比例、不放大小图的策略；文件名仅用于无障碍描述，不额外绘制边框或文件名。
- 共用登录与验证入口、文案和回调后的页面状态，删除正常操作流程中的 Cookie/cURL 手动输入界面。OTP 成功会关闭认证页及验证弹窗。
- 浏览器/WebView 是平台承载能力：Android 验证通过实际站点 JSON 后同步会话并自动返回；Mac 仍由浏览器接续适配器处理。站点要求的人机验证不能由客户端自行替代。
- 网络限流协调继续由公共网络层处理；验证探测也尊重服务器冷却，不循环提交请求。

macOS CI 和 DMG 脚本说明统一使用 `createReleaseDistributable` 与 `binaries/main-release`，避免将遗留的 `binaries/main/app` 封装进新 DMG。两端构建号为 35，关于页面显示 `Lindo v0.2.32 · build 35`。

验证覆盖：偏好迁移与主题选择、原生图标渲染、OTP 返回、宽屏完整操作、窄屏验证恢复、两种宽度的设置页面，以及现有限流回归。UI 截图来自真实 Compose 页面和模拟服务数据，不代表真实账号登录实测。当前 ADB 未连接设备，Android 真机安装和登录仍需设备接入后验证。
