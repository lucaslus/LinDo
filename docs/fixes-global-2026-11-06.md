# 全局修复与创作体验统一

本轮在 `fix/global-composer-consistency` 完成上一轮审查问题的修复。改动保留透明底分类和操作控件，集中统一发帖、回复和修改旧帖的容器、提交位置、输入样式、键盘避让、错误与草稿状态。

- 编辑原文准备完成后才开放输入；保存后同时更新 raw 和 cooked，避免损失格式或再次编辑读到旧内容。快速输入的父状态回传不再重置光标。
- 草稿按账号隔离，在每次修改时保存到本机，再防抖同步云端。同步、提交和清理共用顺序与真实 sequence；恢复时保留编辑类型、目标帖子和回复楼层。退出提供继续编辑、保留草稿、确认丢弃。
- 删除评论、删除草稿、移除收藏、归档私信、全部已读及退出账号共用确认样式。请求中防重复点击；失败时保留数据并显示错误。
- Markdown 预览使用 CommonMark，代码保持字面内容；剧透需要主动揭示。有效 poll option ID 支持真实提交；缺少交互数据时提供原帖入口。未知正文 SVG 保留明确入口。
- 长帖窗口按楼层归并，提供更早楼层加载，跳转未加载楼层时读取目标窗口。Topic Map 只放在真实头帖后；他人徽章页不再混入当前账号数据。
- 授权回调验证 nonce、目标与有效期，成功后消费私钥状态。Android 使用 Keystore 保护认证信息与本机草稿，并排除云备份和设备迁移。
- Gradle daemon 固定 JDK 21，开发脚本尊重兼容的 JAVA_HOME。依赖调整到 Kotlin 2.2.21、Compose 1.9.3、compileSdk 36 的兼容组合，恢复 AAR metadata 检查。

验证包括 Android 与桌面各 52 项单元测试、Debug Lint、Debug 与 Release 构建。Lint 仍有依赖版本、已有 API 弃用、图标与代码建议等警告；未再出现先前的 Kotlin metadata 不兼容诊断。Release 构建产物未配置正式发布签名。

模拟器的创作、删除及归档检查使用隔离工作区和假数据，未向真实账号发送内容或执行删除。实际账号的站点插件、审核队列、附件限制与权限仍需正常使用时进一步验证；本轮不作真机长期内存和 120 Hz 性能保证。审查前保留的阅读计时队列持久化等历史待办也不在本轮已完成声明中。

最终模拟器回归：业务 APK 5 项通过；隔离 fixture 的编辑恢复、删除确认、归档确认 3 项通过；1.6 倍字号的回复框发布操作可见。原始结果和截图在 [修复回归证据](review-evidence/2026-11-06-fixed/)。
