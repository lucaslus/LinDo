# 安全与隐私

LinDo 是 [LINUX DO](https://linux.do) 的第三方客户端。项目没有自建中转后端，也没有接入统计、广告或崩溃上报 SDK。[客户端与官网源码](https://github.com/lucaslus/LinDo)

## 网络通信

| 用途 | 通信对象 |
| --- | --- |
| 论坛浏览、发帖、消息与站点验证 | LINUX DO 服务，包括 `linux.do`、`connect.linux.do` 等 |
| 图片、头像和页面资源 | LINUX DO 的资源服务、Discourse CDN，以及用户打开的帖子资源或外链 |
| 版本检查与更新 | GitHub API 与 GitHub Releases 的下载服务 |
| 域名解析 | 系统 DNS 或内置 HTTPS DNS，取决于平台和连接策略。内置解析器包括阿里云 DNS、DNSPod 与 Cloudflare |

站点验证可能在应用内打开受控网页。社区认证信息用于登录和访问相关社区服务。DNS 查询包含待解析的域名。

## 本机数据与外链

- 登录凭证、账号列表、未发草稿、阅读位置与诊断日志保存在本机应用数据目录。
- 诊断日志对 Cookie 与令牌等敏感字段做脱敏处理。
- 帖子外链显示目标域名确认，可识别部分伪装域名。应用内登录与验证窗口限制顶层页面可访问的站点。

## 校验安装包

Android、macOS、Windows 和 Linux 正式包由公开的 [GitHub Actions 工作流](https://github.com/lucaslus/LinDo/blob/main/.github/workflows/release.yml) 构建。每个 [GitHub Release](https://github.com/lucaslus/LinDo/releases/latest) 附带 `SHA256SUMS.txt`。在本机计算下载文件的 SHA-256 后，可与清单中的同名条目核对。

```sh
# macOS
shasum -a 256 Lindo-*.dmg

# Linux
sha256sum Lindo-*.deb

# Windows PowerShell
Get-FileHash .\Lindo-*-setup.exe -Algorithm SHA256
```

如发现问题，欢迎通过 [GitHub Issues](https://github.com/lucaslus/LinDo/issues) 反馈。
