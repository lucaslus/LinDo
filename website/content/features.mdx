# 功能与设置

## 外观

| 设置 | 说明 |
| --- | --- |
| 浅色 / 深色 | 可手动设置，也可跟随系统 |
| Android 启动图标 | 在「我的 → 应用图标」选择样式。背景可选浅色、深色或跟随系统 |
| 主题色 | 金、蓝、绿、红、紫、青、橙，用在选中项、主要按钮和未读标记上 |
| 字号 | 五档，分别是 80%、90%、100%、110%、120%，会叠加系统字号 |
| 宽屏布局 | 折叠屏与平板默认 50:50 居中左右分栏，可拖拽调整宽度，也可切为单栏扩宽 |
| 动效 | 可以关闭。系统开启"减少动态效果"时也会关闭 |

## 阅读

首页可以按最新、热门、新帖、未读、关注查看，也可以按分类筛选。

正文支持引用、代码、图片和链接预览。投票、公式这类互动内容会提供原网页入口。

回复里会显示被回复人的头像和摘要，点击后跳到对应楼层并短暂高亮，还能跳回原处。

LinDo 会在本机记录阅读进度和未发草稿。编辑器提供 Markdown 预览。

## 账号

点头像可以切换已保存的账号。

### 通行密钥

在 LINUX DO 的「偏好设置 → 安全性」添加通行密钥。Android 可先在支持通行密钥的系统浏览器登录 LINUX DO，再回 LinDo 选择「浏览器授权」。[Discourse 通行密钥说明](https://meta.discourse.org/t/passwordless-login-using-passkeys/285589)

### 跨设备登录

在已登录的设备生成一次性二维码或口令。Android 在「我的 → 扫码 / 口令登录」操作，未登录时也可以从登录页进入。桌面端可在「登录二维码」导入截图或粘贴口令。登录码用于授权另一台设备，请勿公开分享。

## 网络恢复与站点验证

切换 Wi-Fi、移动网络或代理后，客户端会尝试恢复可重试的页面加载。遇到站点验证时，可以在应用内完成，随后接续可恢复的操作。

验证页一直空白，或通过后帖子仍没加载，可以按[站点验证指南](/docs/verification)处理。

## Connect 数据

Connect 页面只显示官方提供的周期指标。拿不到周期数据时，会标明显示的是账户累计数据，不会据此推算等级。
