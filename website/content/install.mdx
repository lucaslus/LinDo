# 下载与安装

所有安装包都发布在 [GitHub Releases](https://github.com/lucaslus/LinDo/releases/latest)。

## Android

<Steps>

### 下载 APK

在 Releases 页面下载最新的 `.apk` 文件。

### 允许安装

首次安装时，系统可能会要求允许当前浏览器或文件管理器“安装未知应用”。

### 登录

打开 LinDo，选择“使用 LINUX DO 登录”，或使用系统浏览器授权。

</Steps>

## macOS

下载 `.dmg`，打开后将 LinDo 拖入“应用程序”文件夹。需要 macOS 11 或更高版本。

<Callout type="warning">
  若系统提示“无法验证开发者”，请在“系统设置 → 隐私与安全性”中选择仍要打开。
</Callout>

## Windows

下载 `.msi` 安装包并按提示完成安装。
