# 下载与安装

所有安装包与校验清单（`SHA256SUMS.txt`）均发布在 [GitHub Releases](https://github.com/lucaslus/LinDo/releases/latest)，也可直接在官网[下载区](/#download)按当前系统获取。

## Android

<Steps>

### 下载 APK

在官网下载区点击 **下载 APK**（或在电脑端点击 **手机扫码**），获取最新 `.apk` 安装包。正式发布的 APK 面向 arm64，最低系统版本为 Android 7.0。

### 允许安装

首次安装时，系统可能会提示允许当前浏览器或文件管理器“安装未知应用”。

### 登录

打开 LinDo 后，可选择应用内网页登录、浏览器授权或扫码 / 口令登录。点「先逛逛」可以浏览公开话题。

</Steps>

## macOS

根据芯片架构下载对应的 `.dmg`（M 系列芯片选择 **Apple Silicon**，旧款 Mac 选择 **Intel 芯片**），打开后将 LinDo 拖入“应用程序”文件夹。需要 macOS 11 或更高版本。

<Callout type="warning">
  若首次打开时系统提示“无法验证开发者”，请前往“系统设置 → 隐私与安全性”，在底部点击“仍要打开”。
</Callout>

## Windows

支持 Windows 10 / 11（64 位）。普通用户推荐下载 **安装程序（`-setup.exe`）** 按向导完成安装；企业或批量部署环境也可选择 **MSI 安装包（`.msi`）**。


## Linux

GitHub Releases 提供 x86_64 安装包。Debian / Ubuntu 系选择 `.deb`，Fedora 等 RPM 系选择 `.rpm`。也可下载 `.AppImage`，赋予执行权限后运行。

```sh
chmod +x Lindo-*-linux-x86_64.AppImage
./Lindo-*-linux-x86_64.AppImage
```

Arch Linux / Omarchy 可从源码构建。克隆仓库后进入 `packaging/arch`，以普通用户运行 `makepkg -si`。[打包配置](https://github.com/lucaslus/LinDo/tree/main/packaging/arch)
