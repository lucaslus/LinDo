# LinDo

LinDo 是 [LINUX DO](https://linux.do) 的第三方客户端，支持 Android、macOS、Windows 和 Linux。

[下载安装](/docs/install) · [遇到站点验证怎么办？](/docs/verification) · [功能与设置](/docs/features)

## 技术栈

| 平台 | 实现 |
| --- | --- |
| Android | Kotlin Multiplatform + Compose Multiplatform |
| macOS / Windows / Linux | Tauri 2 + Rust + React |

源码在 [GitHub](https://github.com/lucaslus/LinDo)。
